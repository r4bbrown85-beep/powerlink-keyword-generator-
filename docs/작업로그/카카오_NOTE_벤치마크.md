## NOTE 업로드 CSV 포맷 (13열, 헤더 2줄)

```
1행: 집행년도|집행월|업종|유형x목표|소재형식|비용|노출수|클릭수|친구 추가수|재생수|발송수|열람수|시간대
2행: year|month|category_nm|product_nm|creative_type|budget|imps|click|friends|views|sent|read|time
3행~ 데이터
```

- `집행월`은 숫자가 아니라 **"1월"** 문자열. 빈 지표는 공란이 아니라 **0**.
- `유형x목표` = 관리자 화면의 `product_nm`. 일반은 `카카오톡 채널x도달`(소문자 x, 공백 없음), **CPT는 `카카오 비즈보드 CPT X 도달`(대문자 X, 양쪽 공백)** — 표기가 다르다.
- **광고주·캠페인 열은 업로드 스키마에 없다**(벤치마크라 익명화). 집계 키로만 쓰고 최종 출력에서 뺀다.
- `시간대`는 **CPT 전용**(`18시~20시` 형식, `22시~24시`까지).
- 업로드 화면 경고: 파일 암호화 해제 후 업로드 / 지표명 변경 시 업로드 불가 / **같은 년·월 재업로드 시 기존 데이터 삭제 후 교체**(→ 정정 가능).

## 변환 파이프라인

원본 CSV(106열, 1만 행대) → 업로드 CSV(13열, 250~300행)

1. 필요 열만 추출(차원 9 + 지표 7 + **확장 3열**)
2. **업종 채우기** — 원본 업종 칸은 100% 공란. 광고주명으로 매칭표 조회, 없으면 `기타`
3. **유효 유형x목표 필터** — 가이드 8종에 없는 `포커스 보드`·`프로필 풀뷰`·`CPT 채팅탭` 제외
4. **규칙 3: 유형이 공란이면 CPT로 분류** ← 이걸 빠뜨려서 5·6월 92건이 누락될 뻔했다
5. **소재형식 변환** — 카카오톡 채널은 앞에 "메시지" 붙임(`캐러셀 피드`→`메시지 캐러셀피드`), `비디오 네이티브`→`동영상 네이티브`
6. **익스팬더블 판별** (원본은 전부 '이미지 배너'로 내려옴)
   - `동영상 자동 재생수 (확장)` > 0 → **익스팬더블 동영상형**
   - `이미지1 노출수 (확장)` > 0 → **익스팬더블 멀티형**
   - `노출수 (확장)` > 0 (나머지) → **익스팬더블 이미지형**
   - 근거: CPT 로우데이터 파일 `소재_벤치마크_PIVOT` 시트 주석 *"노출수(확장) 1이상 = 비즈보드 익스팬더블 집행"*
7. **집계** — 연도+월+업종+광고주+유형x목표+소재형식 로 SUM → 광고주 열 제거 후 출력
8. CPT는 별도 파일로 분리

```python

        if ext_img1 > 0: return "익스팬더블 멀티형"
        if ext_imp > 0:  return "익스팬더블 이미지형"

is_cpt = typ.startswith("카카오 비즈보드 CPT") or typ == ""   # 규칙 3
```

**이 파일은 이미 NOTE 업로드 형태다.** 업종·시간대·소재·비용·노출수·클릭수가 전부 들어 있어서 **업종 매칭가이드 조회조차 필요 없다.** 25년 12월 업로드본 CPT 32행과 대조한 결과:

- **비용은 구좌 단가(라운드값)** — 32/32행이 100만원 단위로 딱 떨어진다
- **노출수가 0인 행이 없다**(32/32) — 성과지표가 CPT 업로드의 핵심이다

### ✅ 해결: 성과지표는 월별 로우데이터에 있다 — 조인으로 완성 (2026-10-06)

**팀장 지적으로 바로잡음.** 월별 로우데이터에 `유형 = '카카오 비즈보드 CPT'` 행이 있고 여기에 **광고주·캠페인·비용·노출수·클릭수**가 다 들어 있다. 없는 건 **시간대**뿐이다. 반대로 계약파일에는 시간대·상품옵션이 있고 성과지표가 없다. → **두 파일을 조인하면 완성된다.**

**핵심: 로우데이터 CPT 행은 소재 단위로 쪼개져 있다.** 캠페인별로 합산해야 계약금(구좌 단가)과 맞는다.
```
스킨푸드_MO비즈보드CPT_2/1 12~14시   →  9행 합계 24,000,001  ↔  계약금 24,000,000 ✓
아이프로스펙트 구찌 _1/13 12시        →  6행 합계 28,000,001  ↔  계약금 28,000,000 ✓
roborock 202602_kakao-cpt_s10max   →  4행 합계 28,000,001  ↔  계약금 28,000,000 ✓
```
(6월은 구좌마다 소재가 1개씩이라 우연히 1:1로 보였다 — 다른 달에서 바로 깨진다.)

**조인 절차**
1. 로우데이터에서 `유형 == '카카오 비즈보드 CPT'` 행만 추출
2. `(광고주, 캠페인)`으로 묶어 비용·노출수·클릭수 **합산** → 이게 구좌 1건
3. 계약파일에서 같은 달 + `계정명 == 광고주` + `|계약금 - 비용합| ≤ 2%` 인 건을 찾음
4. 후보가 여럿이면 **캠페인명에서 날짜를 파싱**해 가린다(`6/17`, `0605`, `26.06.27`, `0325 14:` 등). 밑줄이 `\b`를 막으므로 정규식에 단어경계를 쓰면 안 된다
