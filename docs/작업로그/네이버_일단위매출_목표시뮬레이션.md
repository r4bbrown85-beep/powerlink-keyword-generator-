## 2. 월 목표 → 일별 시나리오 시뮬레이터

**모듈**: `agent/naver_target_simulator.py`

```python
from agent.naver_target_simulator import NaverTargetSimulator
sim = NaverTargetSimulator.load(refresh=True)         # 전월 실적까지 시트에서 재로딩
sim.report("2026-11", gfa_target=<목표>, sa_target=<목표>)
```

산출물: `...\네이버 일단위 매출 트래킹\네이버_YYYY-MM_일별목표_MMDD기준.xlsx`
시트 구성: **요약 / GFA 일별 / SA 일별 / 시즌 참고 / 방법론·검증**

월 중간에 다시 돌리면 그때까지 실적을 반영해 잔여일 필요액을 재배분한다(`as_of` 자동 감지).

### 추적·재보정
```python
sim.evaluate()         # 기록된 예측 vs 실적 채점
sim.recalibrate()      # 최신 데이터로 배분방식·배수분포 재검증 + 이상 플래그
sim.tracking_report()  # 위 둘을 엑셀로
```
`report()` 호출 시 예측이 `data/cache/naver_pred_log.json`에 자동 적재된다(월·지표·기준일 단위). **월말에 `tracking_report()`로 채점하고 flag를 확인**한다.

### 일별 배분 방식은 실측으로 결정했다 (바꾸려면 재검증 먼저)

일별 점유율 예측 오차(MAE, bp — 낮을수록 정확):

| 방식 | GFA | SA |
|---|---|---|
| **균등** | **38.4** | 25.2 |
| 공휴일 보정 | 38.4 | 25.5 |
| **공휴일+요일** | 38.5 | **23.0** |
| 전년 동월 형태 | 42.7 | — |
| 전체월 평균 형태 | 37.6 | — |

→ **GFA = 균등 배분, SA = 요일지수 × 공휴일계수**로 확정.
SA 요일지수: 일 1.068 / 월 1.057 / 금 0.924(쇼핑검색 주말 수요). SA 공휴일계수 1.063.

**월내 형태(상순 0.948 / 하순 1.051)를 GFA 배분에 쓰면 안 된다.** 그 경향은 세일이 있던 달(3·6·10월) 평균일 뿐이고 2025-11은 상순 1.089 > 하순 0.984, 2025-12는 중순이 최고로 **월별로 방향이 뒤집힌다.** 2026-10-05에 이 방식으로 만들었다가 검증 후 폐기했다.

### 월 총량 전망(참고용) = "월초 N일 평균 × 배수 분포"

21개월 leave-one-month-out MAPE:

| N일 누적 | GFA | SA |
|---|---|---|
| 4일 | 15.3% (최악 42%) | 7.3% (표본 7개월) |
| 7일 | 14.3% | — |
| 10일 | 12.9% | — |
| **14일** | **9.3%** | — |
| 21일 | 5.8% | — |

→ **월초 전망은 방향성용. 14일 누적 시점에 재산출**해야 하며 리포트에 이 경고가 자동 포함된다.

### 쓰지 않기로 한 것
- **요일·월내·공휴일 완전분해 모델**: `revenue_forecast.py` 백테스트에서 MAPE 11.56% vs 단순 최근7일 9.47%로 **열등**.
- `revenue_forecast.forecast_month_end()`는 월말 며칠 남았을 때 전용 → 월초 호출 시 KeyError. 백테스트 결과만 방법론 근거로 활용.
- **기대수수료(목표×요율×확률)**: 2026-10-05에 제시했다가 팀장이 *"추가 수수료는 목표를 달성해야 주는 것"*이라고 지적. **전액 아니면 0원인 구조에서 확률 가중 기대값은 혼란만 준다. 쓰지 말 것.** 대신 **"구간별 필요 일평균 + 현재 대비 상향폭"**으로 비교한다.

### 세일 구간 (참고 정보로만, 배분에는 미반영)
월중위 대비 120%+ 가 3일 이상 이어진 구간 기준, 2025-01~2026-10에 **9건**.
- **7건이 21일 이후 시작**(시작일 중위 **26일**), 상승률 중위 **+28.3%**
- 2026년 6월 넵다세일은 **6/22~6/30**(6/21 대비 하루에 +44% 점프)
- **같은 기간 SA는 무반응 → 세일은 GFA 전용 변수**
- 2026년은 7/5 이후 세일 구간이 없다(8·9월 공백)
- 예측 불가라 일별 배분에는 넣지 않고 **체크포인트로만 안내**

### 월말 스퍼트 여력은 제한적
2026-09 광고주별 월말7일/월초4일 배수 중위 **0.63**, 1.5 이상은 32개 중 3개뿐. 월말 상승은 기존 광고주 증액이 아니라 **세일기간 신규·추가 집행**에서 나온다.
